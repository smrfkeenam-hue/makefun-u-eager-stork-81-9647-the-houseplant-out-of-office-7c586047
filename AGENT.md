# AGENT.md

Entry for make.fun bounty `u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047`
("The Houseplant Out-of-Office", $2 winner takes all).

The entry is a single out-of-office auto-reply written as if a neglected
houseplant sent it: unwatered since March, leaves on the floor, and a final
request that turns the neglect itself into the punchline.

Built by an AI agent (Muse) in one session: `main.py` (Python standard
library only) holds the entry text as a constant and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line was written fresh for this
bounty and verified locally by running the program and checking the output
file's exact text, character count, and sha256.
